# 2-way-studio-monitor-build
Passively crossed 2-way studio monitor build. Flat Eq response for near-field precision. 


### Cabinet Dimensions
Passively crossed 2-way studio monitor build. 

**External height:** 13 in

**External width:** 8 in

**External depth:** 10.5 in

**Internal Vol:** 0.390 ft^3

**Woofer Diameter:** 6.91 in

**Tweeter Diameter:** 1.71 in

**Enclosure material:** 3/4 in. MDF, spray paint


### Signal Chain
Scarlett Focusrite -> Dual RCA to TRS cable -> Fosi V3 Amplifier -> speaker wire w/ banana plugs -> banana jacks for each monitor
